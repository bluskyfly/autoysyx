# # 乘除法器

在现代程序中, 乘除法是很常见的操作. 对于需要进行乘除法操作的程序来说, 软硬件的不同配置会影响程序执行的功能表现和性能表现, 具体如下:

硬件| 程序| 运行时环境| 行为  
---|---|---|---  
不支持乘除法指令| 包含乘除法指令| 不模拟| 程序无法执行  
不支持乘除法指令| 包含乘除法指令| 抛出非法指令异常后, 用加减操作法模拟乘除操作| 程序可以执行  
不支持乘除法指令| 编译出用加减操作模拟乘除操作的函数| -| 程序可以执行  
支持乘除法指令| 包含乘除法指令| -| 程序可以以较高性能执行
