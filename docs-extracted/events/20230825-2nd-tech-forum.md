论坛聚焦开源芯片技术生态（使用开源EDA和开源IP设计开源芯片）， 涵盖开放指令集（RISC-V）及其软硬件系统、开源芯片设计、开源EDA工具链、开源IP、芯片人才培养等主题， 旨在为相关爱好者提供交流平台，围绕开源芯片分享技术工具、学习经验和心得感想。 同时设置学生专场，鼓励学生围绕RISC-V开展相关工作并分享。 论坛计划设置长报告、短报告和poster等报告类型，欢迎大家积极投稿。

## [#](#稿件征集) 稿件征集

### [#](#稿件主题) 稿件主题
- “一生一芯”，包括但不限于： 分享“一生一芯”学习心得；分享有利于“一生一芯”学习的工具；
- 分享技术技巧或成果（可包括系统软件、RISC-V指令集的理解、处理器设计、总线设计、外设设计、调试技巧等）；
- 学生作品专场 围绕RISC-V软件或硬件的作品或成果，包括但不限于模拟器、编译器、指令扩展、FPGA调试、板卡设计等。
- 开源EDA和开源IP 分享开源EDA的学习和使用经验，如使用开源EDA仿真和设计芯片等，工具如verilator/yosys/iEDA/openRoad/klayout等；
- 分享开源IP的开发和验证，如处理器核、SDRAM、SPI、VGA、Ethernet等；
- 人才培养和开放教育 围绕RISC-V及计算机系统人才培养，分享经验和心得；围绕开放式教育或公益教学，分享方案或心得，包括但不限于 MOOC、社区学习、大学计划等。
- 高校课题组招生和企业招聘 “一生一芯”注重培养计算机软硬件协同设计能力，欢迎高校课题组和企业投稿招聘，包括但不限于保研、直博，以及实习生、校招、社招。论坛现场会设置展板统一展示。
